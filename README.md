# 📊 Vrinda Store Annual Report 2022 (Excel Dashboard)

## 📌 Overview  
This project presents an interactive **Excel dashboard** for analyzing the annual performance of *Vrinda Store (2022)*. It provides insights into sales trends, customer behavior, and order distribution using visual charts and pivot analysis.

---

## 🎯 Objectives  
- Track monthly sales and order trends  
- Compare sales between men and women  
- Analyze order status (Delivered, Cancelled, Returned)  
- Identify top-performing states  
- Understand customer age & gender distribution  
- Analyze sales channels performance
